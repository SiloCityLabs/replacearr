# Screenshots

UI captures for the Replacearr web app. Sensitive values (API keys) are redacted.

Refresh with:

```bash
python3 -m venv /tmp/replacearr-shot-venv
/tmp/replacearr-shot-venv/bin/pip install websocket-client
/tmp/replacearr-shot-venv/bin/python scripts/capture-screenshots.py --profile desktop
/tmp/replacearr-shot-venv/bin/python scripts/capture-screenshots.py --profile mobile --port 9335
```

| --- | --- |
| [Desktop](desktop/README.md) | 1440×900 |
| [Mobile](mobile/README.md) | 390×844 |
